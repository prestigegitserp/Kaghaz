# کاغذ — نسخهٔ اول راستهٔ تعاملی

**Kaghaz v1.0.0** · بازار کاغذ، به زبان فارسی و در مقیاس انسانی.

این پروژه از صفر برای تجربهٔ «دیدن بازار، شناختن جنس و ساختن غرفه» نوشته شده است. چهار مخزن قبلی مطالعه شده‌اند؛ کد آن‌ها بدون تغییر به پروژه منتقل نشده است. هدف این نسخه، یک پایهٔ اجرایی و قابل ارائه برای راستهٔ سه‌بعدی است. پذیرش کیفیت بصری نهایی باید با مشاهدهٔ خروجی روی دستگاه هدف انجام شود؛ به‌خصوص قبل از ارائه به کارفرما.

**[باز کردن بازار روی GitHub Pages](https://prestigegitserp.github.io/Kaghaz/)**

انتشار اصلی از شاخهٔ `main` با گردش‌کار `.github/workflows/pages.yml` انجام می‌شود. هر تغییر روی `main` پس از گذراندن آزمون‌ها و ساخت پروژه، خودکار روی GitHub Pages منتشر می‌شود. در تنظیمات Pages مخزن، منبع انتشار باید `GitHub Actions` باشد. مسیر فایل‌های سه‌بعدی، بافت و فونت از زیرمسیر همان سایت ساخته می‌شود.

## آنچه اجرا می‌شود

- یک راسته با **۸ غرفهٔ نمونه و ۲۴ کالا**؛ غرفه‌های تحریر، گلاسه، مقوا، رنگی و بسته‌بندی.
- معماری طاق‌دار، آجر و گچ گرم، کف سنگ، تابلوهای خوانای فارسی، قفسه‌های پر، پیشخوان و جزئیات کار فروشنده.
- بند کاغذ با تناسب واقعی‌تر و لفاف چاپی، لبهٔ لایه‌لایه، پالت چوبی، کارتن با دیواره و زبانه، نمونه‌رنگ بادبزنی و رول با هستهٔ توخالی و سطح مقطع لایه‌لایه. رول فقط در غرفهٔ مربوط به بسته‌بندی حضور دارد.
- گردش با صفحه‌کلید، نگاه با کشیدن تصویر، نمای آزاد، رفتن به غرفه، ورود از مسیر کنار پیشخوان، نقشه و تصویر خروجی.
- جست‌وجوی فارسی با پشتیبانی از شکل عربی «ک/ی»، اعداد فارسی/عربی و چند واژه؛ فیلتر صنف و غرفه.
- جزئیات کالا و استودیوی سه‌بعدی قابل چرخش؛ نشان‌شده‌ها و فهرست استعلام با تعداد، واحد، یادداشت، دریافت فایل و کپی متن.
- ساخت و ویرایش **۲ غرفهٔ شخصی** و حداکثر **۴۰ کالای شخصی** در این نمونه؛ نام، رنگ و صنف روی صحنه و کاتالوگ اثر می‌گذارد.
- کاتالوگ PDF تا ۱۰ مگابایت؛ مدل GLB مستقل تا ۲۵ مگابایت با سقف هندسه و تکسچر. فایل‌ها داخل همین مرورگر در IndexedDB می‌مانند.
- کیفیت خودکار، جزئیات بیشتر، متعادل و سبک. رندر هنگام سکون متوقف می‌شود؛ فونت و بافت و رمزگشاهای مدل همراه پروژه‌اند.
- کاتالوگ و استعلام مستقل از موفقیت WebGL قابل استفاده‌اند. موتور سه‌بعدی به‌صورت یک بخش جدا دانلود می‌شود.

## اجرا؛ بدون Unreal یا حساب سرویس دیگر

Node.js **22.18 یا جدیدتر** لازم است. Node 24 در ساخت فعلی استفاده شده است.

```bash
npm ci
npm run dev
```

آدرسی را باز کنید که Vite چاپ می‌کند؛ معمولاً `http://localhost:5173` است.

```bash
npm test
npm run build
npm run preview
```

خروجی `dist/` یک سایت ایستا است. برای اجرا، پوشه را از طریق وب‌سرور سرو کنید؛ بازکردن `index.html` با `file://` مسیر پشتیبانی‌شده نیست. `base: './'` است، بنابراین زیرمسیر `/Kaghaz/` هم قابل میزبانی است. با انتخاب فایل GLB یا PDF هیچ فایلی به سرور فرستاده نمی‌شود.

اسکریپت `prepare-assets.mjs` رمزگشاهای Draco و Basis را از نسخهٔ قفل‌شدهٔ Three.js در `public/decoders` آماده می‌کند. نیازی به CDN زمان اجرا نیست.

## ساخت غرفه و آوردن کالا

۱. «غرفهٔ من» را باز کنید. نام، توضیح، صنف، رنگ و اولین محصول را وارد کنید.

۲. در صورت نیاز PDF یا GLB انتخاب کنید. GLB باید نسخهٔ ۲ و مستقل باشد؛ فایل با تکسچر یا buffer بیرونی رد می‌شود.

۳. پس از ذخیره، غرفه در یکی از دو جای انتهای راسته می‌نشیند. از پنجرهٔ ویرایش غرفه، «مدیریت کالاهای این غرفه» را برای افزودن و ویرایش محصولات بیشتر باز کنید.

۴. GLB در گوشهٔ نمایش شیء قرار می‌گیرد و در محدودهٔ نمایش اندازه می‌شود. این ورودی **برای نمایش یک شیء** است؛ بارگذاری اسکن کامل فروشگاه به‌عنوان جایگزین کل معماری هنوز پیاده نشده است.

۵. از «دربارهٔ این تجربه» فایل پشتیبان JSON بگیرید. در ویرایش غرفه، «ورود فایل پشتیبان» داده‌ها را با فضای فعلی ادغام می‌کند. JSON شامل خود فایل‌های PDF و GLB نیست؛ اصل آن‌ها را جدا نگه دارید.

## تصمیم معماری

TypeScript + Vite + Three.js؛ بدون لایهٔ React در حلقهٔ رندر. پوسته و کاتالوگ DOM هستند. بخش تجارت، دادهٔ غرفه و هندسه از هم جدا شده‌اند. `InstancedMesh` برای بسته‌ها، کاغذها، قفسه و سنگ‌های تکراری استفاده می‌شود و هر غرفه یک بخش فضایی مستقل است.

```text
src/domain/model.ts       قرارداد داده، جست‌وجو، اعتبارسنجی و متن استعلام
src/domain/catalog.ts     دادهٔ نمونهٔ غرفه‌ها و کالاها
src/domain/storage.ts     ذخیرهٔ محلی داده و فایل
src/main.ts               رابط فارسی، گردش کار و مدیریت غرفه/کالا
src/scene/world.ts        دوربین، تعامل، کیفیت و چرخهٔ رندر
src/scene/booths.ts        مغازه، چیدمان و محصولات سه‌بعدی
src/scene/architecture.ts  پوستهٔ راسته و طاق‌ها
src/scene/batch.ts         رندر گروهی تکرارها
src/scene/materials.ts     مصالح، بافت‌ها و تابلوها
src/scene/importer.ts      ورود GLB و حدود بودجهٔ دارایی
src/scene/studio.ts        بررسی قابل چرخش کالا
```

## وضعیت تست و مرزهای نسخه

۱۰ آزمون منطق و قرارداد فایل و ساخت TypeScript/Vite با موفقیت اجرا شده‌اند. جزئیات در [گزارش اعتبارسنجی](docs/VALIDATION.md) آمده است. پیش‌نمایش داخلی محیط ساخت در دسترس نبود؛ خروجی خصوصی منتشر شد، اما ورود مرورگر بررسی‌کننده مجاز نشد. در نتیجه **تست بصری، تعامل مرورگر و FPS دستگاه واقعی تأیید نشده‌اند**. ساخت موفق، اثبات فوتورئال بودن یا تضمین سرعت روی موبایل نیست.

این نسخه backend تجاری، حساب فروشنده، انتشار غرفه بین دستگاه‌ها، قیمت زنده، پرداخت یا ارسال واقعی استعلام ندارد. نام‌های نمونه به معنای همکاری با کسبهٔ واقعی نیستند. معماری الهام‌گرفته از راستهٔ ایرانی است و سند بازسازی واقعی بازار بهارستان نیست. مصالح تصویری تولیدشده‌اند؛ اسکن یا PBR اندازه‌گیری‌شده نامیده نمی‌شوند.
