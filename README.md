## تجربهٔ سالن

- روی کف کلیک کنید تا مسیر حرکت از میان میزها پیدا شود. برای تغییر نگاه، تصویر را بکشید. غرفه‌ها و میزهای قابل کلیک، روی نقشه هم قابل انتخاب‌اند.
- در **ساخت جعبه** عرض، عمق، ارتفاع و جنس را تغییر دهید. الگوی تخت و تا شدن مرحله‌ای ضلع‌ها، زبانه‌ها و در را با کشیدن پیش‌نمایش از زاویه‌های مختلف ببینید.
- در **نور و چاپ** دو جنس را انتخاب کنید، مرز تصویر را بکشید و تغییر چاپ را با سه منبع نور و زاویه‌های مختلف مقایسه کنید. نمایش چاپ تقریبی و برای مقایسهٔ کیفی است.
- از **میز نمونه‌ها** می‌توانید مدل نزدیک تحریر، گلاسه، کرافت و کارتن را باز کنید. چیدمان برش، انتخاب، استعلام و غرفهٔ شخصی با فایل GLB و PDF هم در دسترس‌اند.
- میز ساخت جعبه، تست چاپ و گالری رندر روی مرورگر بدون WebGL قابل استفاده‌اند. سفارش‌ها، فایل‌ها و غرفهٔ شخصی محلی ذخیره می‌شوند.

## ساخت و آزمون

```bash
npm ci
npm test
VITE_PUBLIC_BASE=/Kaghaz/v4/ npm run build
npx playwright install chromium
node tests/v4-browser.mjs
```

Node 24 در CI استفاده می‌شود. آزمون مرورگر روی WebGL2 نرم‌افزاری Chromium و حالت موبایل بدون WebGL اجرا می‌شود. خروجی نهایی سه‌بعدی در دستگاه‌های مختلف به GPU، اندازهٔ صفحه و کیفیت انتخابی بستگی دارد.

گردش‌کار مرکزی GitHub Pages، ریشه و `/v1/` را از commit اصلی نسخهٔ اول و سه مسیر دیگر را از شاخه‌های مستقل می‌سازد. جزئیات مصالح، رندر و بازتولید در [راهنمای دارایی‌های نسخهٔ چهارم](docs/V4_ASSETS_FA.md) است.
