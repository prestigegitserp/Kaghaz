## دیدن جنس

روی کف کلیک کنید یا از W A S D برای حرکت استفاده کنید. دکمهٔ طبقه، مسیر رسیدن به پله و گذر از آن را اجرا می‌کند. هر خانوادهٔ جدید یک نمونهٔ نماینده در کاتالوگ و روی یکی از میزها یا استندهای مغازه دارد. رنگ، گرماژ و ابعاد هر کالا در مشخصات همان کالا آمده است.

| نمونه | جزئیات قابل بررسی |
|---|---|
| خودکپی | لبهٔ چسب‌خورده، برگ‌های رنگی و فرم چاپ‌شده |
| فویل و مرواریدی | بازتاب فویل در نور مایل و خطوط روی مقوا |
| لیبل رول | هسته، حلقه‌های مقطع و لیبل‌های جدا از زیره |
| میکروفلوت | موج پیوسته میان رویه‌ها و برش ورق در چند ارتفاع |
| کالک | خطوط چاپی زیر برگ و ناحیهٔ هم‌پوشانی |
| پنبه‌ای دست‌ساز | بافت دانه‌دار و لبهٔ نامنظم |
| مقوای چندلایه | رویهٔ چاپی، لایه‌های روشن و مغزی خاکستری |
| لانه‌زنبوری | هندسهٔ سلول‌ها و رویهٔ جداشونده |

برای دیدن فایل کامل Cycles در گالری، «بزرگ‌نمایی» یا «تصویر کامل» را انتخاب کنید. یازده رندر شامل راهروی ۳۸۴۰ × ۲۱۶۰، دو قاب پاساژ با عرض ۲۵۶۰ و هشت عکس نزدیک کالا با عرض ۲۳۰۴ پیکسل‌اند. نسخهٔ سبک تصویر پیش از درخواست فایل کامل بارگذاری می‌شود.

هفت کارگاه نمونه‌ها، باز کردن لفاف، نور و چاپ، تا زدن جعبه، باز کردن رول، چاپ چهاررنگ و چیدمان پالت در دسترس‌اند. استعلام‌ها و غرفهٔ شخصی در مرورگر ذخیره می‌شوند. برای بازکردن نسخه‌های قدیمی از منوی «نسخهٔ ۶» استفاده کنید. فضای ذخیرهٔ این نسخه و نسخه‌های قبلی جداست.

## ساخت و آزمون

```bash
npm ci
npm test
VITE_PUBLIC_BASE=/Kaghaz/v6/ npm run build
npx playwright install chromium
node tests/v6-browser.mjs
```

آزمون‌ها مسیر پله، هفت کارگاه، مدل‌های جدید، فیلتر کالا، بزرگ‌نمایی فایل اصلی، حالت موبایل بدون WebGL و تفکیک ذخیرهٔ مرورگر را بررسی می‌کنند. مشخصات تجاری و خروجی ابزارهای محاسبه دادهٔ نمایشی‌اند.

## بازتولید مدل و رندر

الیاف، لبه‌ها، ساختار داخلی ورق و طرح‌های چاپی نسخهٔ ششم در ابزارهای این پروژه ساخته می‌شوند. کف، چوب و اندود از [مصالح نسخهٔ سوم](docs/V3_ASSETS_FA.md)، [نسخهٔ چهارم](docs/V4_ASSETS_FA.md) و اسکن [Interior Tiles](https://polyhaven.com/a/interior_tiles) استفاده می‌کنند. فایل [asset-manifest.json](public/v6/asset-manifest.json) ابعاد، اندازه و هش نسخهٔ وب هر دارایی را ثبت می‌کند.

با Blender 4.3، Python، Pillow، NumPy و فونت‌های Noto Sans Arabic و DejaVu Sans:

```bash
python tools/assets/prepare_v3.py --fetch
python tools/assets/prepare_v4.py --fetch
python tools/assets/prepare_v5.py --fetch
python tools/assets/prepare_v6.py
blender -b --factory-startup --python-exit-code 1 --python tools/assets/render_v6.py -- --samples 160
blender -b --factory-startup --python-exit-code 1 --python tools/assets/render_v6_passage.py -- --samples 128 --time-limit 430
python tools/assets/pack_v6.py --denoise
```

بستهٔ `oidn` برای نویزگیری در مرحلهٔ آخر لازم است. برای بسته‌بندی مستقیم خروجی خام می‌توان گزینهٔ `--denoise` را حذف کرد.
