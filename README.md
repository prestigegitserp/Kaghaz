## دیدن بازار و بررسی کالا

- **قدم زدن در راسته** با چهار قاب دوربین و سه حالت نور ورودی، غروب و چراغ‌های راسته. قفسه‌ها و تابلوهای فارسی برای هشت غرفه و ۲۴ کالای نمونه آماده‌اند.
- **میز بررسی جنس** با نمای کلی، لبه یا مقطع، ماکرو، تغییر زاویهٔ نور از ۷ تا ۷۶ درجه و فاصلهٔ اجزا. در بند نیمه‌باز، لفاف و ورق‌های بیرون‌آمده اجزای جداگانه‌اند.
- **شش قاب Cycles** از ورودی، داخل غرفه، بند نیمه‌باز، رول، کارتن و پالت. گالری بزرگ‌نمایی و دریافت تصویر کامل دارد. تصویر ورودی، گالری و برش بدون WebGL قابل استفاده‌اند.
- **چیدمان برش** با ابعاد ورق مادر و قطعه، حاشیه، فاصله و اجازهٔ چرخش ۹۰ درجه. تعداد، پرت و وزن با بهترین الگوی میان ردیف‌ها و ستون‌های نواری محاسبه می‌شود.
- **کاتالوگ، مقایسه، استعلام و غرفهٔ شخصی** با مدیریت کالا، مدل GLB مستقل و PDF. داده‌ها و پیوست‌ها روی مرورگر ذخیره می‌شوند. پشتیبان JSON نسخه‌های پیشین برای انتقال مشخصات قابل وارد کردن است. فایل‌های مدل و PDF را دوباره انتخاب کنید.

معماری از راستهٔ بهارستان الهام گرفته است. مدل و رندر کاتالوگ، نمونه‌ای از خانوادهٔ جنس را نمایش می‌دهد. ابعاد واقعی هر کالا را از مشخصات همان کالا بخوانید.

## اجرا و اعتبارسنجی

```bash
npm ci
npm run dev
npm test
VITE_PUBLIC_BASE=/Kaghaz/v3/ npm run build
npx playwright install chromium
node tests/v3-browser.mjs
```

Node.js 22.18 یا جدیدتر، با Node 24 در CI. آزمون مرورگر از WebGL2 نرم‌افزاری Chromium استفاده می‌کند و حالت بدون WebGL را هم بررسی می‌کند. اندازه‌گیری کارایی GPU لپ‌تاپ به همان دستگاه نیاز دارد.

گردش‌کار Pages روی `main` نسخهٔ اول را از commit ثابت، سپس `v2` و `v3` را از شاخه‌های خودشان می‌سازد. خروجی در چهار مسیر `/`، `/v1/`، `/v2/` و `/v3/` منتشر می‌شود. روی هر شاخهٔ نسخه، فهرست، نما و فضای ذخیرهٔ مرورگر مستقل است.

## تولید دارایی و توسعه

شش مدل جدید، فهرست وزن فایل، اثر انگشت و تعداد مثلث‌ها در [مانیفست نسخهٔ سوم](public/v3/asset-manifest.json) ثبت شده‌اند. چهار مدل ثابت از نسخهٔ دوم در کاتالوگ زنده دوباره استفاده می‌شوند. هندسه، شناسهٔ کالا، مسیر دوربین و دادهٔ غرفه مستقل‌اند. راه ساخت دارایی، منابع اسکن و توضیح خروجی در [راهنمای دارایی‌ها](docs/V3_ASSETS_FA.md) آمده است.
