# کاغذ ۵ · پاساژ کاغذ بهارستان

بازار تعاملی فارسی در دو طبقه با ویترین‌های شیشه‌ای، راه‌پلهٔ قابل پیمایش، بالکن مشرف به راهرو و قفسه‌های پُر کاغذ. پلان و نام فروشگاه‌ها برای این پروژه طراحی شده‌اند. نسبت راهرو به ویترین‌ها، نور فروشگاه و چیدمان کالا از عکس‌های پاساژها و فروشگاه‌های کاغذ تهران الهام گرفته‌اند.

## گردش و میزهای کار

روی کف کلیک کنید یا از W A S D برای حرکت و از کشیدن تصویر برای تغییر نگاه استفاده کنید. در نقشه طبقه، فروشگاه و میز را انتخاب کنید. دکمهٔ طبقه، مسیر رسیدن به پله و گذر از آن را اجرا می‌کند. برای بررسی بافتِ نزدیک، نمای فروشگاه و ویترین هم در منوی دوربین در دسترس‌اند.

| میز | تعامل |
|---|---|
| نمونه‌ها | باز کردن مدل کالا، چرخش و نمای نزدیک |
| نور و چاپ | مقایسهٔ دو جنس با مرز متحرک و سه نور |
| ساخت جعبه | تغییر ابعاد و جنس، نمای تخت و تا شدن پویای جعبه |
| باز کردن بند | کنار زدن فیلم و آزاد کردن تسمه با دو کنترل مستقل |
| بازکردن رول | کشیدن کاغذ و محاسبهٔ طول و وزنِ باقی‌مانده با ابعاد انتخابی |
| چاپ چهاررنگ | روشن و خاموش کردن رنگ‌ها، جابه‌جایی رجیستر و دیدن نتیجهٔ ترکیب |
| چیدمان پالت | تنظیم ابعاد و وزن کارتن و مشاهدهٔ تعداد، جهت و لایه‌ها |

خروجی چاپ، وزن رول و ظرفیت پالت برای بررسی و مقایسه در همین شبیه‌ساز تقریبی‌اند. جست‌وجو، انتخاب کالا، چیدمان برش، پیش‌نویس استعلام و ساخت غرفه با PDF و GLB همچنان در دسترس‌اند. داده‌ها در مرورگر ذخیره می‌شوند. روی مرورگر بدون WebGL تصویر پاساژ، گالری رندر و کنترل دوبعدی کارگاه‌ها قابل استفاده است.

## ساخت و آزمون

```bash
npm ci
npm test
VITE_PUBLIC_BASE=/Kaghaz/v5/ npm run build
npx playwright install chromium
node tests/v5-browser.mjs
```

Node 24 در CI استفاده می‌شود. آزمون مرورگر مسیر پله، کارگاه‌ها، ثبت غرفه و پیش‌نویس استعلام را روی WebGL2 نرم‌افزاری و مسیر رندر و کنترل دوبعدی را در اندازهٔ موبایل و حالت بدون WebGL بررسی می‌کند.

## مصالح و رندر

کف سرامیکی از اسکن [Interior Tiles](https://polyhaven.com/a/interior_tiles) با مجوز [CC0](https://polyhaven.com/license) و رنگ و زبری تنظیم‌شده ساخته شده است. الوار، اندود و الیاف بسته‌بندی از [مصالح نسخهٔ سوم](docs/V3_ASSETS_FA.md) و [چهارم](docs/V4_ASSETS_FA.md) استفاده می‌کنند. طرحِ تسمه و لفاف، لیبل‌های فارسی و چیدمان هر فروشگاه برای این نسخه ساخته شده‌اند. سه مدل تازهٔ آمادهٔ مرورگر شامل بستهٔ تسمه‌دارِ روی پالت، چرخ‌دستی باردار و وسایل روی پیشخوان‌اند. [اندازه، هش و تعداد مثلث‌ها در مانیفست](public/v5/asset-manifest.json) ثبت شده است.

چهار قاب راهرو، مغازه، بالکن و بار با Blender 4.3 و Cycles نورپردازی و رندر شده‌اند. نمای زنده با Three.js و پلان و مصالح مشترک اجرا می‌شود. بازتولید فایل‌ها به Blender 4.3، Python با Pillow و NumPy، فونت‌های Noto Sans Arabic و DejaVu Sans و برای نویزگیری به بستهٔ اختیاری `oidn` نیاز دارد.

```bash
python tools/assets/prepare_v3.py --fetch
python tools/assets/prepare_v4.py --fetch
python tools/assets/prepare_v5.py --fetch
blender -b --factory-startup --python-exit-code 1 --python tools/assets/build_v5.py -- --samples 64
python tools/assets/pack_v5.py --denoise
```
