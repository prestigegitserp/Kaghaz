# قرارداد دارایی نسخهٔ دوم

مدل‌ها با اسکریپت Blender ساخته می‌شوند؛ هیچ دارایی بازار از اینترنت برداشته یا به‌عنوان اسکن واقعی معرفی نشده است. نقشه‌های PBR با Pillow و NumPy تألیف شده‌اند. تصاویر Cycles ثبت مرورگر نیستند.

| مدل | اندازه و جزئیات |
|---|---|
| بند A4 | کاغذ داخلی ۲۱۰ × ۲۹۷ × ۵۰ میلی‌متر؛ لفاف، چاپ و تاهای انتهایی جدا |
| پالت | ۱۲۰۰ × ۸۰۰ میلی‌متر؛ بلوک، تیرک، تخته و میخ |
| بند ورق | حدود ۷۱۰ × ۹۹۰ میلی‌متر؛ ورق‌های لایه‌ای، دو تسمه و برچسب |
| کارتن | ۴۲۰ × ۳۲۰ × ۲۸۰ میلی‌متر؛ ضخامت، لاینر، زبانهٔ باز یا درز و نوار بسته |
| رول | قطر ۶۴۰ میلی‌متر، ارتفاع ۹۲۰؛ سوراخ واقعی ۱۱۰ میلی‌متر، حلقه‌های پیچش و دنبالهٔ آزاد |
| دفتر | بلوک ورق، دو جلد، عطف و بخیهٔ عطف |
| نمونه‌رنگ | هشت برگ نازک حول محور اتصال |
| پیشخوان | عرض ۳٫۶۵ متر؛ قاب گردو، پنل رنگ، نوار برنجی و صفحهٔ سنگ |

محور عمودی Blender برابر Z و glTF برابر Y است. تبدیل با exporter انجام می‌شود؛ منشأ هر دارایی در کف قرار دارد. GLB مستقل است و تصاویر داخلی WebP به‌صراحت با `EXT_texture_webp` مشخص شده‌اند. هندسه فشرده‌سازی مخرب ندارد. حداکثر تعریف runtime برای هر فایل ۴ MiB و ۶۰هزار مثلث است؛ مقدار واقعی در manifest ثبت شده است.

`part` در extras برای لفاف، ورق، تسمه، زبانه و جلد استفاده می‌شود. با این حال تعامل کالا همچنان از proxy و شناسهٔ دامنه می‌آید؛ اسکن جدید ملزم به حفظ نام مش‌های فعلی نیست. cache مشترک دارد؛ هنگام نزدیک شدن، گروه دارایی کامل و به‌صورت اتمی جایگزین fallback می‌شود. اگر فایل کامل بارگیری نشود، fallback حذف نمی‌شود. نمایشگر استودیو و بازار فایل مشترک دارند؛ اجزای تکراری غرفه instance می‌شوند.

مصالح با `sRGB` برای رنگ و فضای خطی برای roughness/normal خوانده می‌شوند. normal map مطابق OpenGL +Y است. این نقشه‌ها تخمینی و طراحی‌شده‌اند؛ reflectance اندازه‌گیری‌شده نیستند. مدل مرجع SKU، پارامترهای ابعاد سفارش یا رنگ دقیق کاغذ فروشنده را تضمین نمی‌کند.

رندرهای گالری: نمای کلی، پیشخوان و انبار؛ Cycles CPU، ۲۴۰ نمونه، AgX، بدون denoiser. بعد از بازبینی، دوربین انبار به داخل غرفه منتقل شد تا دیوار جلوی رول را نگیرد. اسکریپت اصلی نیز با همان موقعیت اصلاح شده است.

برای پذیرش روی دستگاه هدف، ابتدا 1080p و کیفیت متعادل، سپس حالت پرجزئیات را در مسیر چهار غرفه بررسی کنید: بند در فاصلهٔ نزدیک و دور، سوراخ و مقطع رول، زبانه و داخل کارتن، سایهٔ تماس پالت، برخورد ورودی غرفه، چرخش استودیو، باز کردن اجزا و تغییر نور. پس از چند ثانیه سکون باید رندر متوقف شود. GPU timing و FPS با ابزار خود مرورگر روی دستگاه واقعی سنجیده شوند؛ آمار CPU داخل سایت جایگزین آن نیست.
