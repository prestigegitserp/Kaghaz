# Changelog

## 1.0.0 — 2026-11-17

Initial implementation of the Persian interactive paper-market experience.

- Metric arcade architecture and eight distinct merchant layouts, with twenty-four illustrative products.
- Instanced stock, wrapped reams, flat pallets, hollow paper rolls, cartons with folds and swatch fans.
- Navigation, shop focus and entrance, minimap, adjustable quality and on-demand rendering.
- Search, catalog, product studio, saved items and local inquiry export.
- Two local custom booths with up to forty custom products, PDF and bounded GLB import, local asset persistence and JSON backup.
- Strategy, asset pipeline, acceptance guide, provenance and explicit validation limits.

Build and logic tests passed. Browser visual quality, actual device performance, and end-to-end file import remain unverified because the preview relay was unavailable and browser authentication was blocked by automatic review.
